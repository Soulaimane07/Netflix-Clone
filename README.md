# 🎬 Movify — Video streaming platform

## 🚀 Project Overview

Movify is a full-stack web application designed to provide a rich streaming experience with movies and series.  
It features dynamic content fetching, user authentication, profile management, and personalized recommendations.

Built with modern technologies, Movify demonstrates skills in frontend development, backend APIs, cloud deployment, and integration with third-party services.

---

## 🧩 Features

- Browse and search movies and series by genres, popularity, or networks  
- User authentication & profile management (sign up, login, multiple profiles)  
- Track viewing history and resume watching  
- Responsive UI with smooth navigation and animations  
- Secure backend with REST API built in Spring Boot  
- Cloud deployment using AWS services (EC2, S3, CloudFront, RDS, ElastiCache)  
- Integration with payment gateway (Stripe) for subscription management  
- Real-time data fetching and caching to improve performance

---

## 🛠️ Technologies Used

### Frontend
- React.js  
- Redux / Context API (for state management)  
- CSS / Tailwind

### Backend
- Java Spring Boot  
- RESTful API design  
- MySQL (RDS) and Cassandra (Keyspaces) databases  
- AWS Redis
- Stripe API for payments  

### Cloud & DevOps
- AWS EC2 for backend hosting  
- AWS S3 + CloudFront for static frontend hosting and CDN  
- AWS RDS for relational database  
- AWS Keyspaces for Cassandra NoSQL database  
- Docker (for staging dev)
